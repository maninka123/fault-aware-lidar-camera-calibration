# Example image provenance

These are actual simulator outputs, not photographs or validated sensor measurements.

- `environments.png`: labelled contact sheet of the four procedural Blender scene previews, resized for documentation. Built from `blender/scenes/{warehouse,laboratory,urban,corridor}/preview.png`.
- `warehouse-camera.png`: unmodified RGB from the historical `warehouse_avia_v2` run, capture 0000.
- `warehouse-lidar-overlay.png`: the corresponding evaluation overlay; colours show the Livox scan pattern projected onto the same image.
- `urban-camera.png`: unmodified 32-sample urban RGB from the 9 November 2026 sample comparison, capture 0000; OptiX, denoising and adaptive sampling enabled.

The scene geometry is generated by `blender/build_scene.py`. The urban lighting uses the CC0 Industrial Sunset 02 HDRI by Sergej Majboroda / Poly Haven; provenance and download verification are in [ASSETS.json](../ASSETS.json).

Large generated scenes and datasets are excluded from this repository. These small examples illustrate output appearance; they do not establish photorealism, physical sensor fidelity or calibration accuracy.
