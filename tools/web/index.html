Ground truth

Rig pose in the world

World: X forward, Y left, Z up (m); angles in degrees. The rig origin is the LiDAR frame.

LiDAR → camera · relative pose

Camera position in the LiDAR frame and its rotation relative to the default forward mounting (roll about X, pitch about Y, yaw about Z of the LiDAR; +yaw turns left). This becomes the ground-truth T_CL.

Unfinished runs in this folder
This folder is inside OneDrive, which uploads every file as it is written and can slow the PC during a long capture. Saving to a folder outside OneDrive (for example C:\SimData) and moving the finished datasets afterwards is lighter.
Continue keeps the captures that already finished and only produces the rest; the result is identical to a run that never stopped. Redo moves the unfinished attempt to _incomplete (kept, not deleted) and captures everything again. A run made with different settings is always redone.
Every configuration is its own self-contained folder directly inside this one. Existing folders are never overwritten: they are skipped, or, if you untick the box, the configuration is saved again as a new copy (named _v2). A mass capture that stopped half way can be run again with the same options and the same folder to do only what is missing.
